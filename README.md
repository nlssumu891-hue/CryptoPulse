# CryptoPulse Intelligence

Mobile-friendly Node.js web application for crypto market monitoring and SMC-style technical analysis.

## Run
`npm start` then open `http://localhost:3000`.

## Deploy
Use a Node.js host that supports a start command. Start command: `npm start`. Node 20+ (22 recommended). The server reads the host-provided `PORT`.

No private API key is required for the public market endpoints used by this MVP.

Live data depends on upstream public APIs and can be temporarily rate-limited or unavailable. Analysis is informational and is not financial advice or a profit guarantee.
